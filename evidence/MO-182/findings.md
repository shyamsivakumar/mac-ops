# MO-182 · Findings

Full report with sources: [report.md](report.md). This file is the short answer form required by issue #121.

- **Does omp load pi packages?** Not automatically. omp's config and extension roots are its own (`~/.omp/agent`; `src/sdk.ts:552`, `src/config.ts:81`), and a grep of omp's source finds no `pi-package` handling, so pi's `pi install` result is invisible to omp. omp *can* load a pi package's declared entry point, because it reads the `pi` manifest key (`src/extensibility/plugins/manager.ts:300`, `src/extensibility/extensions/directory-resolution.ts:69`, `src/discovery/helpers.ts:842`) and ships a legacy pi extension loader (`src/extensibility/plugins/legacy-pi-compat.ts:2724`).
  **But the package would not register a working provider in omp as written.** It calls `pi.registerProvider(nativeProvider)` with one argument (`index.ts:238`), which pi supports (`dist/core/extensions/types.d.ts:1403`) and omp does not (`src/extensibility/extensions/types.ts:2033` declares only `registerProvider(name, config)`; `src/config/model-registry.ts:3508`). It also imports `registerApiProvider` from `@earendil-works/pi-ai/compat` (`index.ts:21`), which omp's bundled pi-ai does not export (it has `registerCustomApi`, `@oh-my-pi/pi-ai/src/api-registry.ts:74`), and `getBuiltinModels` from `@earendil-works/pi-ai/providers/all` (`index.ts:22`), a subpath omp's bundled pi-ai does not have. Static reading, not a runtime test: verifying it needs an install, which this ticket forbids.
- **Versions found vs required.** Node v22.23.1 (needs 22.18+, `package.json` `engines.node`) and Claude Code 2.1.323 (needs 2.1.265+, `src/cli-requirements.ts` `MIN_SUPPORTED_CLI_VERSION`; structured import needs 2.1.292). Both satisfied.
- **Memory cost.** ~500 MB per parked Claude process, one per session, at most four parked (`README.md` "Processes and memory"; `src/provider-config.ts:65` `MAX_PARKED = 4`): ~0.5 GB per live session, ~2 GB ceiling.
- **Usage-credit guard default.** Blocked. `PI_CLAUDE_CLI_ALLOW_USAGE_CREDITS` is unset by default; a call charged to usage credits ends with a "billing" error that pi does not retry, and the charged call is already paid for (`README.md` "Usage-credit guard"; `src/usage-credits.ts`).
- **Recommendation.** Do not install into omp under this ticket, and do not install it later without a code change: pi already has the package installed on this Mac and is the supported path. If omp is to use the Claude subscription, the work is an omp-native provider (or a change to the package that supports both hosts) in a separate approved ticket.
