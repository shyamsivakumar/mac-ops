## Generic runner design

Own the runner in **mac-ops**, not in each product repository. A versioned, reviewed per-repo registry contains `{repo, check command, full command, status context}`; commands are trusted configuration, not pull-request-provided shell. On a merge-train candidate, resolve the exact merged tree, run its configured check once in an isolated clean checkout under `heavy --review`, and post pending/success/failure for the exact candidate SHA. On each main commit, run the configured full command and post its distinct SHA-bound result. Never reuse a result across different trees, check definitions, dependencies or environments; only deduplicate concurrent identical jobs after recording those inputs. Fail closed on checkout, execution, timeout, status publication or interrupted runner; publish durable logs and queue/run timings. Serialize or otherwise coordinate publication so stale jobs cannot overwrite newer state. No deploy is admitted from a PR-tier result where a full main result is required.

SRW's publisher should be migrated onto that shared owner after its implementation and behavior are reviewed. As of this snapshot [SRW PR #548](https://github.com/shyamsivakumar/strategy-replay-workbench/pull/548) is open, and `scripts/srw_agent_check_publisher.mjs` is not on remote main; do not assume it has shipped. The PR's publisher uses `srw/agent-check`, a clean exact-SHA checkout, a heavy check, a SHA-specific PASS marker, credential-name scrubbing, and a journal/pending-status guard against stale overwrites. Preserve its actual exact-SHA/status, deployment and failure semantics during migration, with shadow comparison before cutover. The gate reviews the diff; the merge train must invalidate results whenever its candidate changes. Fast and full commands must be explicit per repo; never silently substitute diff-based selection for unproven coverage. Record 10 representative queue and execution samples, p50/p95, slowest step, and a deliberate failure before declaring the 2-minute target met. The 60-second SRW watch is a proposal, not an approved policy.
